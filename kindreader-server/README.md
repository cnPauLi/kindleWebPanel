# KindReader 本地测试环境

用于在开发阶段，把本地页面提供给 App 内 WebView 加载测试的临时环境。

> ⚠️ 这是**开发测试用**的临时目录，不参与 App 打包，可随时删除。

## 目录结构

```
kindreader-server/
├── page/
│   └── index.html      测试页面（墨水屏优化样式）
├── serve.py            本地 HTTP 服务器（Python3 标准库，零依赖）
└── README.md           本说明
```

## 快速开始

### 1. 启动服务器

```bash
cd kindreader-server
python3 serve.py          # 默认端口 8080
# 或指定端口
python3 serve.py 9000
```

启动后会打印本机局域网地址，例如：

```
本机访问 : http://127.0.0.1:8080/
局域网   : http://192.168.1.100:8080/
```

> 服务器以 `page/` 目录为站点根目录，所以直接访问根路径 `/` 即可，
> 无需再加 `/page/` 前缀。

### 2. 查看本机局域网 IP（macOS）

```bash
ipconfig getifaddr en0     # Wi-Fi
ipconfig getifaddr en1     # 有线网卡（视情况）
```

### 3. 在 App 中配置地址

1. 打开 Kindle 上的 App；
2. **快速连点屏幕左上角 5 次**，弹出「设置请求地址」对话框；
3. 填入局域网地址：`http://192.168.1.100:8080/`
   （把 IP 换成上一步查到的实际地址）；
4. 点击「保存」，页面立即加载。

### 4. 修改页面调试

直接编辑 `page/index.html`，然后在 App 里重新触发加载
（返回键回退或重新连点 5 次打开对话框点保存），即可看到最新页面。
服务器已禁用缓存，无需重启。

## 测试要点

页面 `index.html` 会回显以下信息，方便验证：

| 显示项 | 验证内容 |
|--------|----------|
| 页面加载时间 | 确认是实时从服务器返回的内容 |
| 当前完整地址 | 确认请求地址配置正确 |
| URL 参数回显 | 确认带参数请求是否正常 |
| JS 测试按钮 | 确认 WebView 的 JavaScript 已启用 |

## 停止服务器

在运行 `serve.py` 的终端按 `Ctrl+C`。

## 常见问题

- **App 加载不出来？**
  - 确认 Kindle 与电脑在**同一局域网/Wi-Fi**；
  - 确认地址用的是**局域网 IP**（不是 `127.0.0.1`，那是电脑本机回环）；
  - 确认 macOS 防火墙允许 `python3` 接受传入连接。
- **端口被占用？** 换一个端口，如 `python3 serve.py 9000`。
- **想在电脑浏览器先预览？** 打开 `http://127.0.0.1:8080/`。
